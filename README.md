# 🛍️ Crafty Bay

Crafty Bay is a modern **Flutter-based e-commerce mobile application** designed to provide a smooth and user-friendly online shopping experience. Users can browse products, explore categories, manage their cart and wishlist, and customize the app with multiple languages and themes.

## ✨ Features

* 🏠 Modern and responsive home screen
* 🛍️ Browse and explore products
* 📂 Category-based product browsing
* 🔍 Product search
* 🛒 Add and manage products in cart
* ❤️ Wishlist functionality
* 🌐 Multi-language support

  * English
  * বাংলা
  * German
  * Spanish
* 🌙 Light and dark theme support
* 🔄 Provider-based state management
* 🔥 Firebase integration
* 📱 Responsive Flutter UI

## 🛠️ Technologies

* **Flutter**
* **Dart**
* **Provider**
* **Firebase**
* **REST API**
* **Localization**
* **FVM**

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* Git
* Firebase configuration

### Installation

1. Clone the repository:

```bash
git clone https://github.com/rifatHossainDevs/crafty_bay.git
```

2. Navigate to the project directory:

```bash
cd crafty_bay
```

3. Install dependencies:

```bash
flutter pub get
```

4. Configure Firebase for your environment.

5. Run the application:

```bash
flutter run
```
